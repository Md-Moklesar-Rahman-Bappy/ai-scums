# Supported Versions

We follow [Semantic Versioning](https://semver.org/). Security and bug fixes are
applied to the latest stable minor line.

| Version | Supported | Notes |
|---------|-----------|-------|
| 1.x     | ✅ Yes    | Current stable line. Receives security & bug fixes. |
| < 1.0   | ❌ No     | Pre-release / alpha builds are not supported. |

## Policy
- **Patch releases** (`1.0.x`): security and critical bug fixes, backported to the latest `1.x`.
- **Minor releases** (`1.x`): new features, backward-compatible.
- **Major releases** (`2.0`): breaking changes, with migration notes.

## End of Life
A version reaches EOL when a newer minor line is released and announced. Security
fixes for the prior line continue for at least 90 days after a new minor release.
